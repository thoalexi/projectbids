# ProjectBids

I want to create a website that users can enter in what they want done around their house. Contractors would then bid on these projects. an example: i want a small room painted, 9x9x9, i would post a picture and the details of the project and when i would like it done. a painting contractor would then say "i'm interested in doing this project, i'll do it for 150 dollars" and another one could say "i'm interested, i'll do it for 200" and then the user decides which bid they want
